# Predicting-Fraudulent-Transactions-Using-Machine-Learning
A machine learning project that analyzes financial transactions to recognize fraud. Used logistic regression to classify transactions based on different characteristics.
Fraudulent transactions are a major concern for financial institutions. This project applies Logistic Regression to detect fraudulent transactions using real-world financial data. The goal is to build a model that can accurately classify transactions as fraudulent or legitimate, helping prevent financial losses.  
#Key Features  
Exploratory Data Analysis with visualizations  
Data preprocessing (handling missing values, encoding, scaling)  
Training a Logistic Regression model  
Model evaluation using **accuracy, precision, recall, F1-score, and AUC-ROC**  
Confusion Matrix for fraud detection performance  
#Dataset  
The dataset was sourced from [Kaggle](https://www.kaggle.com/datasets/chitwanmanchanda/fraudulent-transactions-data).  
It contains transaction details like amount, sender & receiver balance, and transaction type.  
Fraud cases are highly imbalanced (only a small percentage of transactions are fraudulent).
